# Правила роботи з цим репозиторієм

Файл короткий навмисно. Усе, що можна перевірити машиною, перевіряє
`make check` і `make ui`; тут лишилось те, що машина не ловить.

## 1. Не винаходити те, що вже є

Перед тим як писати розмітку, проводку чи форматування — подивитись, чи їх
уже хтось пише. Спільні шари й межа між ними:

| Що робиш | Чим |
|---|---|
| Поле форми | `web/js/fields.js` — `money`/`pct`/`num`/`date`/`text`/`check`/`selectOf`/`note`/`textarea`/`formHTML` |
| Поле, що вказує на **вже наявну** сутність | `web/js/refs.js` — `refSelect` (брокер, фонд, рахунок НПФ, лот, вклад, потік, валюта), `refSuggest` (ISIN) |
| Таблиця операцій | `web/js/grid.js` — `opsGrid`, `actionsCol`, `rowActions` |
| Створити / виправити / видалити запис | `web/js/crud.js` — `wireCrud`; правка одного поля в рядку — `inlineEdit` |
| Запис на бекенд | `web/js/forms.js` — `apply`/`onSubmit`/`onSubmitFunded`/`onDelete`/`openEdit` |
| Числа, гроші, дати, множина | `web/js/format.js` |
| Довідники значень домену | `web/js/constants.js` (валюти — `CURRENCIES`) |
| Кольори, відступи, розміри | токени `--oi-*`; літералів у CSS немає |

Правило тримається механічно: `make ui-kit-boundary` валить рукописні
`<form>`, `<label>`, `<table>` у `web/js/views/`, трійку валют повз
`CURRENCIES` і будь-який `list="…"` (усередині shadow root `<datalist>`
мовчить — саме так у НПФ рік прожило зламане поле).

Винятки з правила названі поіменно в самому `Makefile`. Якщо додаєш
третій — назви його там і поясни, чому кит йому не годиться.

## 2. Де є операції — там повний КРУД

Сутність, яку можна створити, мусить піддаватись правці й видаленню.
«Видалити й набрати заново» — не спосіб виправити одруківку: разом із
записом зникає те, що на нього посилається (продажі гинуть із лотом), а на
вкладі ще й міняється нарахування.

`wireCrud` дає всі три дії одним викликом саме для цього: доки правку треба
було дописувати окремо, шість PUT-ендпойнтів прожили без жодного екрана.

Якщо операції бракує на бекенді — дописати її там, а не обходити в UI.

## 3. Порожніх швів не заводити

Параметр «про запас», абстракція з одним користувачем, мертвий хук і
закоментований код читаються як зразок і тиражуються. Другий випадок —
привід винести спільне; перший — ні.

Коли щось свідомо НЕ зроблено (сортування колонок, пагінація, форма
створення операції фонду) — це пишеться там, де його шукатимуть, разом із
доводом. Інакше наступний автор винайде його заново.

## 4. Коментар пояснює ЧОМУ

Довгі українські коментарі тут — навантажена документація, а не шум. Вони
описують рішення й ціну, а не переказують код. Виносиш шматок — забирай із
собою його аргумент; видаляєш механізм — лишай абзац про те, чому його
більше немає (як у `disclosure.js` про `section()`).

## 5. Арифметика живе в одному місці

Суму операції, курс, дохідність рахує бекенд. Друга копія в браузері вже
двічі закінчувалась різними числами на одному екрані — розбір лежить у
`internal/api/handlers_whatif.go`. Форма надсилає введене й показує те, що
повернув сервер.

## Перед комітом

```
make check   # gofmt, vet, лінтер, усі grep-межі
make test    # тести під -race (потрібен CGO)
make ui      # синтаксис, граф імпортів, eslint, токени CSS, межа кита
```
